# RUN FREE: Suno draft

A 40-second song about open-sourcing LOW LATENCY. Same style prompt as LOW LATENCY. Made in Suno v6 (take 8b17b58f, 57.6 s).

## Style

```
Dark theatrical electropop, 122 BPM, A minor lifting to C major in the chorus. A driving four-on-the-floor kick, distorted analog synth bass, stabbing synth brass, gothic choir pads, hand claps and a glossy 2009 club-pop production with a crisp modern mix. The intro is a shouted chant in her voice. Verse: confident, deadpan female voice, half spoken, close and crisp, every word clear. Chorus: a huge powerful female belt, a chantable hook, one syllable per note, never rushed. A short song that ends on the last chorus line with a hard stop. Dramatic, fierce, camp, fun.
```

## Exclude

```
Jersey club, bed squeak, phonk, cowbell, hyperpop, UK garage, trance, French house, filter disco, rap, male lead vocal, lo-fi, vinyl crackle, mumbled vocals, slurred vocals, autotune, whisper
```

## Lyrics

```
[Intro - shouted chant over the beat, one word per beat]
Fork it! Clone it! Run it! Own it!
```
